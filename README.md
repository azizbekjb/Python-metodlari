# Python-metodlari

Bu sizga Pythonning standart ma'lumot turlari(matn, ro'yxat, lug'at, qator, to'plam, fayl)ning barcha metodlari haqida ma'lumot beradi.

Agar siz Python dasturchisi bo'lsangiz, maqsadingiz o'sish va rivojlanish bo'lsa bu repo aynan siz uchun.

Har bir metod sodda va tushunarli misollar yordamida tushuntirilgan. 

## Repo haqida qisqacha.
- Barcha fayllar `Jupyter notebook`(.ipynb) faylida yozilgan.
- Qoidalar va misollar O'zbek tilida tushuntirilgan.
- Deyarli barcha ma'lumotlar [www.w3schools.com](https://www.w3schools.com/python) saytidan olingan.

## Repo kimlar uchun?
- Python dasturlash tilini o'rganayotgan, o'rgangan yoki bilimini oshirmoqchi bo'lganlar uchun.
- Backend yoki Sun'iy intelekt mutaxasislari uchun.
